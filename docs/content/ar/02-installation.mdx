## التشغيل في المتصفح عبر CDN و Import Maps

ما تحتاج bundler حتى تستخدم `dn-ioc` في صفحة ويب. المتصفحات الحديثة تقدر تحمّل نسخة ESM المضغوطة مباشرة من الـ CDN:

| الـ CDN | الرابط | ماذا يقدّم |
| --- | --- | --- |
| jsDelivr | `https://cdn.jsdelivr.net/npm/dn-ioc` | `index.min.js` (نسخة ESM مضغوطة) |
| unpkg | `https://unpkg.com/dn-ioc` | `index.min.js` — نفس الملف بالضبط |
| esm.sh | `https://esm.sh/dn-ioc` | نسخة esm.sh المحوّلة الخاصة بها |

بدون تحديد رقم إصدار، يرجّع الـ CDN أحدث نسخة منشورة؛ وفي بيئة الإنتاج تقدر تضيف رقم الإصدار بعد اسم الحزمة إذا حبيت تثبّت الصفحة على نسخة محددة.

إضافة `<script type="importmap">` تخليك تكتب استيراد `'dn-ioc'` مباشرة في ملفاتك، فيشتغل نفس الكود بالضبط سواء بوجود bundler أو بدونه.

```html title="importmap.html"
<!doctype html>
<html lang="en">
  <head>
    <script type="importmap">
      {
        "imports": {
          "dn-ioc": "https://cdn.jsdelivr.net/npm/dn-ioc"
        }
      }
    </script>
  </head>
  <body>
    <script type="module">
      import { bootstrapApp, provide } from 'dn-ioc'

      const greetingRef = provide(() => 'hello, browser')
      const app = bootstrapApp(({ inject }) => {
        document.body.textContent = inject(greetingRef)
      })

      await app.start()
    </script>
  </body>
</html>
```

```html title="direct-cdn.html"
<!doctype html>
```

## إعدادات ESM و TypeScript

`dn-ioc` **تعمل بنظام ESM فقط** — استوردها دائماً بـ `import` بدل `require()` الخاصة بـ CommonJS.

في مشاريع TypeScript، حط `"moduleResolution": "bundler"` داخل ملف `tsconfig.json`. إعدادات Vite وBun وNext.js وAstro و`tsdown` الحديثة أصلاً تستخدم هذا الوضع افتراضياً.

```json title="tsconfig.json"
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "strict": true
  }
}
```

<Callout kind="caution" title="إعدادات NodeNext و Node16 غير مدعومة">

نظام فحص التصريحات `NodeNext` و`Node16` **غير مدعوم**. أبقِ `"moduleResolution": "bundler"` في إعدادات TypeScript التي تتحقّق من الأنواع مع `dn-ioc`.

</Callout>

ولأن النواة تتجنّب `process` وواجهات DOM والمؤقّتات، تظل مزوّداتك محمولة 100% بين Node.js وBun والمتصفحات وWeb Workers وبيئات edge.
