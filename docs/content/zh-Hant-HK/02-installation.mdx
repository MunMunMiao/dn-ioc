`dn-ioc` 係一個零外部依賴嘅純 ESM 套件（minify 後 `4.8 kB`，gzip 後 `1.9 kB`），一行指令就裝好，唔會順手拖一大堆雜七雜八嘅間接依賴入 `node_modules`。你平時個專案用開邊套套件管理工具就照用邊套，喺 Deno 用 `npm:` 或者喺瀏覽器直接拉 CDN 都一樣咁方便。

<Code
  title="install.sh"
  lang="bash"
  code={`npm install dn-ioc
pnpm add dn-ioc
yarn add dn-ioc
bun add dn-ioc
deno add npm:dn-ioc`}
/>

## Deno 免安裝直接用

寫緊單一檔案嘅 Deno 小工具，費事特登開個 `deno.json` 先？Deno 可以直接透過 `npm:` 前綴 import `dn-ioc`。

<Code
  title="deno-import.ts"
  lang="ts"
  code={`import { bootstrapApp, provide, provideFor, token } from 'npm:dn-ioc'`}
/>

## 瀏覽器 CDN 與 Import Maps

喺網頁度用 `dn-ioc` 唔一定要先砌套打包工具（bundler）。現代瀏覽器可以直接由 CDN 載入壓縮好嘅 ESM 版本：

| CDN | URL | 實際派發內容 |
| --- | --- | --- |
| jsDelivr | `https://cdn.jsdelivr.net/npm/dn-ioc` | `index.min.js`（`4.8 kB`，gzip 後 `1.9 kB`） |
| unpkg | `https://unpkg.com/dn-ioc` | `index.min.js` —— 同上面完全同一個檔案 |
| esm.sh | `https://esm.sh/dn-ioc` | esm.sh 自己轉譯出嚟嘅產物 |

唔加版本號後綴嗰陣，CDN 會直接派最新嗰版；線上頁面如果想釘死特定版本，自行喺套件名後面補返版本號就得。

加返段 `<script type="importmap">`，你喺模組入面就可以照寫 `'dn-ioc'` 呢種裸模組路徑（bare specifier），無論有冇 bundler 都唔使改一行業務 code。

<Code
  title="importmap.html"
  lang="html"
  code={`<!doctype html>
<html lang="en">
  <head>
    <script type="importmap">
      {
        "imports": {
          "dn-ioc": "https://cdn.jsdelivr.net/npm/dn-ioc"
        }
      }
    </script>
  </head>
  <body>
    <script type="module">
      import { bootstrapApp, provide } from 'dn-ioc'

      const greetingRef = provide(() => 'hello, browser')
      const app = bootstrapApp(({ inject }) => {
        document.body.textContent = inject(greetingRef)
      })

      await app.start()
    </script>
  </body>
</html>`}
/>

## ESM 與 TypeScript 設定

`dn-ioc` **只提供純 ESM 版本**——請一律用 `import` 載入，唔好再用舊式 CommonJS `require()`。

喺 TypeScript 專案入面，請將 `tsconfig.json` 嘅 `"moduleResolution"` 設做 `"bundler"`。而家主流嘅 Vite、Bun、Deno、Next.js、Astro 同 `tsdown` 預設已經係呢個模式，基本上即插即用。

<Code
  title="tsconfig.json"
  lang="json"
  code={`{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "strict": true
  }
}`}
/>

<Callout kind="caution" title="關於 NodeNext 同 Node16 型別解析">

`dn-ioc` **唔支援** `NodeNext` 同 `Node16` 嘅型別宣告解析模式。凡係需要對住 `dn-ioc` 做型別檢查嘅 `tsconfig.json`，請保持 `"moduleResolution": "bundler"`。

</Callout>

因為核心完全唔會掂 `process`、DOM API 同 timer，你寫好嘅 provider 可以 100% 原封不動喺 Node.js、Bun、Deno、瀏覽器、Web Worker 同 Edge runtime 之間共用。準備好落手砌第一個 app 未？即刻揭去下一篇[五分鐘快速上手](/zh-hant-hk/quickstart/)。
